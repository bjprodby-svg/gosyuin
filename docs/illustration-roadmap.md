# Learn Tab イラスト リプレイス ロードマップ

## Phase 1: 方向性決定（スタイル探索）

### やること
- 3つの異なるスタイル案で**同じシーン**（鳥居でお辞儀）のサンプルイラストを作成
- 比較して1つのスタイルに決定

### スタイル候補

**A. フラットイラスト（Notion/Headspace風）**
- ミニマルな線画、ソフトな色面
- 幾何学的でモダン
- テクスチャなし、クリーンな仕上がり

**B. 和風水彩タッチ**
- にじみ・ぼかしのあるテクスチャ
- 和紙の上に描いたような質感
- アプリの「御朱印帳」テーマと最も一致

**C. 線画 + ワンポイントカラー**
- 細い黒線の線画ベース
- 朱色や藍色など1-2色だけ差し色
- シンプルで上品、和風ガイドブック風

### 成果物
- 1シーン x 3スタイル = 3枚のサンプル画像
- ユーザーが選択 → Phase 2 へ

---

## Phase 2: パイロット制作（3枚）

### やること
- 決定スタイルで**異なるタイプのシーン**を3枚制作
  1. 人物アクション（お辞儀/拍手）
  2. 静物/道具（手水舎/御朱印帳）
  3. 全体俯瞰（参道を歩く）
- アプリに実際に組み込んで画面で確認
- サイズ感、背景色、余白を調整

### 成果物
- 3枚の本番用イラスト（750x500px @3x）
- LearnDetailView に仮組み込み
- フィードバック → 必要なら調整
